# [[a link sits beside the point it supports]]

Put a wikilink right next to the point it backs up, challenges, or extends, so the sentence explains why the two notes are connected. A list of related links at the bottom says they're related but not how. Part of [[write notes around one useful idea]], adapted from Andy Matuschak on [links](https://notes.andymatuschak.org/zF8xCU4BwXwbmSyp7tmff9i) and [precise associations](https://notes.andymatuschak.org/zS27HJzP3uD366crN7PYDQU)

## in practice

- Rereading an older note is a good time to spot links it's missing
- Claim titles make this easy because the link reads as the reason, since [[claim titles make a note reusable wherever it's linked]]
- Links like these are what let [[structure grows from links not folders]] work at all
