# [[a note's h1 is a wikilink to itself]]

A note's H1 is a wikilink to the note itself, like `# [[each note develops one idea]]`. Part of [[owner writing and note preferences]]

- When the note is renamed, Obsidian updates the link, so the heading never drifts from the title
- It also means the heading is the exact note title, lowercase and all
- [[owner writing and note preferences]] shows it in use
