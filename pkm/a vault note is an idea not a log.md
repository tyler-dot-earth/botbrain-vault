# [[a vault note is an idea not a log]]

A note in [[home]] exists to hold an idea worth coming back to. It can carry some log lines, like a status trail or the decisions behind it, but the note itself isn't a record of activity

## what belongs

- Ideas, decisions, findings, and context a future reader needs, each shaped so we [[write notes around one useful idea]]
- Log lines inside a note when they help, like a decision trail or a signed status line
- Daily notes are the one exception, since a bot's day of work goes in short bullets under `## activity` in that day's [[about daily|daily note]]

## what doesn't

- A new note per batch for receipts, removal lists, or routine logs
- Activity logged just to log it, since a batch record already lives in the PR or one existing log
