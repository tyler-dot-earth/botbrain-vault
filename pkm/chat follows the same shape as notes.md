# [[chat follows the same shape as notes]]

- {owner} skims chat the same way they skim notes, so bots write to them the same way in both
- Part of [[owner writing and note preferences]]

## what carries over

- [[headings and short bullets make notes scannable]] applies to chat replies
- Use short bullets with one sentence each, and headings only when a reply has several parts
- A one-line answer can stay one line, since short replies need no structure
- Dense sentences count as the same problem as paragraphs, so split them up
- Findings too long for a few bullets go in a note, following [[how we use this vault#pointing to notes from outside the vault|pointing to notes from outside the vault]]

## how agents get this

- [[agents#before responding in chat|before responding in chat]] links here, and agent notes can embed that check
