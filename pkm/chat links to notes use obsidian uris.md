# [[chat links to notes use obsidian uris]]

When mentioning a note in a chat outside Obsidian, link it with an Obsidian URI so it's clickable, since `[[wikilinks]]` only work inside the vault. Part of [[owner writing and note preferences]]

- The shape is `[note title](obsidian://open?vault={vault-name}&file=folder%2Fnote%20title)`, with the path URL-encoded
- Inside the vault, keep using wikilinks
