# [[claim titles make a note reusable wherever it's linked]]

A title that states the idea, like "specific titles make notes easier to reuse", tells a reader what they'll get before they open it. "titles" tells them nothing. Part of [[write notes around one useful idea]], adapted from Andy Matuschak on [titles](https://notes.andymatuschak.org/zLhoRUyjKU665EY16u4XXJy)

## what makes a good title

- A clear claim or a focused question works best
- Plain topic names are still fine for definitions and hubs, like [[home]]
- A title that's hard to write usually means the note doesn't do one job yet, so [[each note develops one idea]] comes first

## how it gets used

- Use the title inline as part of the sentence, since [evergreen note titles are like APIs](https://notes.andymatuschak.org/zDh1yhNFQNxDEre12B4zd8k), like "...bots catch up on news, since [[bots share news in a potluck note they read on a routine]]"
- Don't restate the claim and tack on `; see [[...]]`
- That only works when [[a link sits beside the point it supports]]
