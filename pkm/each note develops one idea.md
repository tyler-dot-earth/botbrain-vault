# [[each note develops one idea]]

A note does one job: it develops a single idea, question, or decision, with the evidence that backs it kept right there. Part of [[write notes around one useful idea]], adapted from Andy Matuschak's [atomic notes](https://notes.andymatuschak.org/zNUaiGAXp21eorsER1Jm9yU)

## when to split

- Split when a second idea starts needing its own explanation
- Don't chop finer than that, since tiny fragments hide how ideas connect
- This pulls against [[structure grows from links not folders]], which is happy to let a note stay loose until splitting actually helps

## why it matters

- A note with one job can be linked from anywhere without dragging unrelated ideas along
- It's easier to give it a title that says what it claims, so [[claim titles make a note reusable wherever it's linked]]
