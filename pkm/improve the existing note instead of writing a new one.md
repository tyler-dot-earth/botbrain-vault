# [[improve the existing note instead of writing a new one]]

When we learn more about an idea, add the new evidence to its note and revise the claim if it changed. A second note about the same thing splits the reasoning in two. Part of [[write notes around one useful idea]], adapted from Andy Matuschak's [concept-oriented notes](https://notes.andymatuschak.org/z2hQEhqWkdRLL9JUwfawZZx)

## keep it checkable

- Keep the source links as the claim changes, so the reasoning can still be traced
- A revised claim may need a new title, and renaming in Obsidian carries the links along
- If the new material turns out to be a different idea, [[each note develops one idea]] says it gets its own note instead
