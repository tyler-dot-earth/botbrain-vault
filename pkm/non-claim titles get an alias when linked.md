# [[non-claim titles get an alias when linked]]

When a linked title isn't a claim, give it an alias so the sentence still reads naturally, like [[about daily|daily note]]. Part of [[owner writing and note preferences]]

- Claim titles don't need one, since [[claim titles make a note reusable wherever it's linked]] and they read inline as is
- Topic and hub titles like `about daily` are the usual case for an alias
