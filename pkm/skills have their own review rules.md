# [[skills have their own review rules]]

- A `SKILL.md` in [[vault skills live in the skills folder|the vault's skills folder]] is reviewed against three skill conventions, not the note-shape rules

## three skill conventions

- Whether [[a skill's description says what it does and when to use it]]
- Whether [[a skill holds only what an agent needs for the task]]
- Whether [[a skill stays under 500 lines with detail in its own files]]

## upstream skills

- A skill copied from elsewhere names its source in `metadata.upstream` and isn't rewritten here, since it's fixed there
