# [[status lines say who changed a note and why]]

- A dated line in a note's `## Status` section shows who made a meaningful change, so the next reader can trust it or ask

- Add a line after a meaningful change, at the bottom so the section runs oldest first
- Use the shape `- 2026-10-14 (kind/[[example agent]]): added pricing source`
- Name the author as `kind/name`, like `kind/[[example agent]]` or `human`
- For agents, the prefix identifies the app that did the work, even when both app sections belong to the same identity note, as [[one agent can work through several apps]] describes
- Prune old lines once they stop mattering

## timestamped lines

- Outside daily notes, a timestamped line links its date to that day's daily note in the daily note's own format (no alias), like `- [[2026-10-20]] 10:37pm (kind/[[example agent]]): ...` in [[potluck]]
- Activity bullets inside a daily note keep just the time
- Status lines keep a plain date
