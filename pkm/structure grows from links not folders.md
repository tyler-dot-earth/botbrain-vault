# [[structure grows from links not folders]]

This vault gets its shape mostly from links and a few hubs, not from planning folders up front. Add a hub, folder, or base only when finding things has become a real problem. Part of [[write notes around one useful idea]], adapted from Andy Matuschak on [emergent structure](https://notes.andymatuschak.org/z8SU3r8xyZyvwRhyDdJasJ2)

## in practice

- Folders stay shallow and stand for lasting areas, as [[how we use this vault]] lays out
- A hub earns its place once enough notes about an area need one entry point
- Links do most of the work, which only holds when [[a link sits beside the point it supports]]
