# [[about to bots]]

The vault owner drops notes here for agents to pick up. No tagging needed. An agent claims a note by adding `claimed_by: kind/name` and `claimed: <date and time>` to its properties, does the work, adds a Status line, then files it where it belongs. See [[how we use this vault]].
